# Googly Eyes 👀
A simple interactive googly-eyes widget built with inline SVG, CSS, and vanilla JavaScript. The pupils follow your mouse (or finger on touch devices), and the eyes blink randomly to feel alive.

## ✨ Features
- Pupils track the mouse cursor and touch input in real time  
- Random blinking with occasional double-blinks  
- Hover and click/tap effects  
- Fully responsive — scales down on smaller screens  
    
---

## 🛠️ Tech
- SVG for the eye shapes  
- CSS transitions for hover/blink animations  
- Vanilla JS (no dependencies)  

---

## 🚀 Run locally
```
Just open index.html in a browser — no build step needed.  
```
